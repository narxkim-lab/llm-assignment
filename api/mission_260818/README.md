# 🕵️ AI Detective

> OpenAI **Tool Calling**을 활용한 대화형 추리 게임

---

## 📌 프로젝트 소개

**AI Detective**는 플레이어가 탐정이 되어 사건 현장을 조사하고, 용의자를 심문하고, 단서를 분석하여 범인을 찾아가는 대화형 추리 게임이다.

이번 프로젝트의 핵심은 단순한 텍스트 생성이 아니라 **LLM이 Python 함수를 직접 호출하여 게임을 진행한다는 점**이다.

### 사건 설명

한도윤 교수는 자신의 서재에서 숨진 채 발견되었다.

문은 안에서 잠겨 있었고, 외부 침입의 흔적은 발견되지 않았다.

하지만 현장에는 여러 가지 수상한 흔적이 남아 있었다.

플레이어는 단서를 수집하고 용의자의 진술을 분석하여 사건의 진실을 밝혀야 한다.

## 🆚 이전 추리 게임과의 차이점

### 이전 버전

이전 추리 게임은 모든 내용을 LLM이 직접 생성하는 방식이었다.

```text
사용자
   ↓
LLM
   ↓
텍스트 생성
   ↓
게임 진행
```

**특징**

- 모든 사건 정보를 LLM이 생성
- 대화에 따라 단서가 달라질 수 있음
- 설정이 바뀌거나 충돌할 가능성이 있음
- 같은 질문에도 다른 결과가 나올 수 있음

---

### Tool Calling 적용 버전

이번 프로젝트에서는 사건 데이터를 Python에 저장하고, LLM은 필요한 도구를 선택하는 역할만 수행한다.

```text
사용자
   ↓
LLM
   ↓
Tool 선택
   ↓
Python 함수 실행
   ↓
사건 데이터 조회
   ↓
LLM
   ↓
게임 진행
```

**특징**

- 사건 데이터를 Python이 직접 관리
- LLM은 필요한 도구만 호출
- 모든 단서가 고정되어 있음
- 일관성 있는 게임 진행 가능
- 게임 로직과 데이터를 분리하여 관리 가능

|일관성|낮음|높음|
|확장성|프롬프트 중심|도구 추가 중심|
