# 🕵️ Detective AI

AI와 함께 사건을 해결하는 대화형 추리 게임입니다.

`OpenAI API`와 `Streamlit`을 활용하여 구현했으며, 사용자는 용의자를 조사하고 단서를 수집하여 범인을 추리할 수 있습니다.

---

## 📌 프로젝트 소개

Detective AI는 `LLM`의 **멀티턴(Multi-turn) 대화 기능**을 활용한 추리 게임입니다.

사용자는 질문을 통해 단서를 수집하고, AI는 사건 진행자 역할을 수행합니다.

`messages` 배열을 사용하여 이전 대화 내용을 기억하므로, 단서를 정리하거나 이전 질문을 기반으로 새로운 정보를 얻을 수 있습니다.

---

## 🎮 주요 기능

### 🔍 단서 수집

사용자는 자유롭게 질문할 수 있습니다.

- 집사는 어디에 있었어?
- 정원사에 대한 단서를 알려 줘.
- 사건 현장에서 발견된 물건이 있어?

---

### 📝 단서 정리

지금까지 수집한 단서를 정리할 수 있습니다.

```text
단서 정리
```

---

### 🕵️ 범인 추리

범인을 찾았다면 정답을 입력합니다.

```text
범인은 정원사다.
```

정답을 맞히면 게임이 종료됩니다.

---

### 🎲 랜덤 사건 생성

새 게임 버튼을 누르면 다른 사건이 생성됩니다.

현재 구현된 사건은 다음과 같습니다.

|사건|용의자|
|---|---|
|💎 사라진 다이아몬드|집사, 요리사, 정원사|
|🖼️ 박물관 그림 도난 사건|경비원, 관장, 청소부|
|📝 시험지 유출 사건|교사, 학생, 행정 직원|
|💍 호텔 보석 절도 사건|투숙객, 직원, 매니저|

## 🧠 동작 구조

```text
사용자 질문
        ↓
messages 배열에 저장
        ↓
OpenAI API 호출
        ↓
AI가 단서 제공
        ↓
messages 배열에 응답 저장
        ↓
이전 대화 기억
        ↓
범인 추리
```

## 🚀 실행 방법

### 1. 패키지 설치

```bash
uv pip install openai streamlit
```

### 2. 환경 변수 설정

```bash
export OPENAI_API_KEY=your_api_key
```

### 3. 애플리케이션 실행

```bash
uv run streamlit run app.py
```
